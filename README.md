# Hollywood Celebrity Fake Face Generation Using Generative Adversial Network(GAN).
In this project, Fake face images of Hollywood actors and actresses (close to Real Images) were generated using 
Generator Model of Generative Adversial Network. Then the Discriminator was asked to distinguish these Fake Images 
from Real Images Images of Hollywood actors and actress which the Discriminator failed to recorgnize and suggested 
these Fake Images to be Real Images.
# Dataset Description:
This dataset contains images of 18 Hollywood celebrities with 100 images of each celebrity. The people in this 
dataset are:

1. Angelina Jolie
2. Brad Pitt
3. Denzel Washington
4. Hugh Jackman
5. Jennifer Lawrence
6. Johnny Depp
7. Kate Winslet
8. Leonardo DiCaprio
9. Megan Fox
10. Natalie Portman
11. Nicole Kidman
12. Robert Downey Jr.
13. Sandra Bullock
14. Scarlett Johansson
15. Tom Cruise
16. Tom Hanks
17.Will Smith

The Deep Convolutional Generative Adversial Network used for the Generator and Discriminator Model was trained for
30 epochs.
